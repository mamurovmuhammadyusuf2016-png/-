# 2. Переадресация с рекламной SIM-карты

Клиенты продолжают звонить на привычный номер из рекламы. Задача — перевести эти
звонки на виртуальный номер Zadarma, где их обработает описанная логика.

---

## Какую переадресацию выбирать

| Тип | Когда срабатывает | Стандартный код |
|---|---|---|
| **Безусловная** | всегда, телефон даже не звонит | `**21*<номер>#` |
| **Занято** | вы сбросили вызов или говорите | `**67*<номер>#` |
| **Нет ответа** | никто не взял трубку N секунд | `**61*<номер>#` |
| **Недоступен** | телефон выключен или вне сети | `**62*<номер>#` |
| **Все три условные сразу** | занято + нет ответа + недоступен | `**004*<номер>#` |

**Рекомендуется `**004*`** — одна команда включает все три условия. Это и есть
«условная переадресация» из ТЗ: владелец сначала видит звонок сам, и только
неотвеченный вызов уходит в систему автообработки.

> Безусловную переадресацию (`**21*`) включайте, только если владелец вообще не хочет
> принимать звонки на рекламную SIM напрямую — тогда все звонки сразу идут в систему.

## Как включить

Наберите на телефоне с рекламной SIM-картой как обычный номер и нажмите вызов.
Номер Zadarma указывайте в международном формате со знаком «+».

```
**004*+998712000000#          — включить все условные переадресации
**61*+998712000000**20#       — «нет ответа» с задержкой 20 секунд
**21*+998712000000#           — безусловная (если нужна)
```

Задержка в коде `**61*` задаётся последним параметром и принимает значения
5, 10, 15, 20, 25, 30 секунд. 20 секунд — разумный компромисс: владелец успевает
взять трубку, звонящий не ждёт слишком долго.

## Как проверить и отключить

```
*#004#          — показать статус условных переадресаций
*#61#           — статус «нет ответа»
*#62#           — статус «недоступен»
*#67#           — статус «занято»

##004#          — отключить все условные переадресации
##21#           — отключить безусловную
##002#          — отключить ВСЕ переадресации разом
```

## Особенности операторов Узбекистана

Коды выше — стандарт GSM, они работают у Beeline, Ucell, Mobiuz, UMS и Perfectum.
Есть нюансы:

- **Услуга должна быть подключена.** У некоторых операторов «Переадресация вызова»
  — отдельная услуга, включается в личном кабинете или через службу поддержки.
  Если код возвращает ошибку — начните с этого.
- **Формат номера.** Если код с «+» не принимается, попробуйте номер без плюса
  в национальном формате.
- **Тарификация.** Переадресованный сегмент вызова оплачивает **владелец SIM-карты**
  по своему тарифу, как исходящий звонок на номер назначения. Если виртуальный номер
  Zadarma зарубежный, это международный вызов — считайте стоимость заранее.
  **Виртуальный номер той же страны заметно дешевле.**
- **Приложения-звонилки** (личный кабинет оператора, мобильное приложение) часто
  позволяют включить то же самое через меню — это надёжнее, чем USSD.

## Проверка связки

1. Включите переадресацию (`**004*<номер Zadarma>#`).
2. Позвоните на рекламный номер с другого телефона и **не берите трубку**.
3. Через 15–25 секунд звонок должен уйти на Zadarma — в логах сервиса появится
   запись `Обработан входящий звонок` с решением.

```bash
curl -H "Authorization: Bearer $ADMIN_TOKEN" https://calls.example.com/admin/calls?limit=5
```

Если записи нет — звонок до Zadarma не дошёл: проверьте статус переадресации (`*#004#`)
и то, что виртуальный номер направлен на АТС (см. [docs/01](01-zadarma-setup.md)).

## Важное следствие для логики

При условной переадресации в систему попадают **только неотвеченные** звонки.
Разговор, на который владелец ответил лично, до сервиса не доходит и в базе не
отражается — значит, время «последнего звонка» для такого абонента не обновится.

Если нужно учитывать вообще все обращения, включая отвеченные лично,
используйте безусловную переадресацию `**21*`: тогда каждый звонок сначала проходит
через АТС, и вся история попадает в базу.
